# 本地 Agent 与订阅额度协作指南

本指南说明如何在不购买外部按量付费 API Key 的前提下，用你手头已有的订阅制 AI 工具驱动本地小说写作台。

## 方式一：零配置直连（推荐新手，1 分钟上手）

直接让支持本地文件读写的桌面 Agent（如 Codex、Cola、Antigravity、Gemini 桌面端、Claude Code）关联你的小说目录：

1. 在 `小说台.html` 中管理设定集、大纲、人物状态卡和章节正文。
2. 需要续写或出细纲时，在 Agent 对话框里直接说：
   - `请按写作包协议读取《雨夜来信》的 00~03 档案和上一章结尾，先给我第 2 章细纲。`
   - `细纲确认，请按细纲续写第 2 章正文并写入 正文/第02章.md。`
3. 切回 `小说台.html` 点一下「刷新」，直接继续精修。

## 方式二：一键复制写作包（适配任意网页端会员）

如果你习惯用网页版 Gemini / ChatGPT / Claude 的订阅会员：

1. 点击「一键复制写前上下文包」。
2. 页面会自动把本书 `00~03` 四份档案、上一章末尾以及 当前书绑定的风格卡与写作 Skill打包到剪贴板。
3. 粘贴进你已登录的网页聊天框，生成后拷回编辑区按 `Cmd+S` 保存。

## 方式三：台内一键调用本机已登录官方 CLI（进阶可选）

初始化已经包含桥接服务，不需要 Agent 再手写接入代码。先安装并登录自己要使用的客户端，再按下面的方式启动：

```bash
cd /path/to/MyNovels
python3 server.py --open
# 8788 已占用时：python3 server.py --port 8789 --open
```

macOS 也可以双击生成目录内的 `启动写作台.command`。服务仅监听 `127.0.0.1`；服务默认加载初始化目录，也可登记其他书架目录，右侧即可检测客户端、选择模型、生成并预览结果。静态模式通过浏览器目录授权读写；服务模式仅通过已登记的书架 ID 读写 Markdown，服务不会把小说目录作为静态网站公开。

### 模型与网络

- agy：通过 ACP `session/new` 读取 `availableModels` 和 `currentModelId`；生成时使用 CLI 的 `--model`。
- Codex：通过 app-server 的 `model/list` 和 `config/read` 读取可选模型及实际配置默认值；生成时使用 `codex exec --model`。
- Cola：通过 `cola model list --json` 和 `cola model current --json` 读取真实目录与当前全局模型。当前版本的 `cola message` 没有单次选模参数，因此工作台使用客户端默认；客户端选 Auto 时用 Auto，选具体全局模型时跟随该选择。其他模型在目录中展示为不可选，不自动切换全局设置。
- 目录短暂缓存 60 秒；「重新检测」强制刷新。查询失败会显示原因，不用预设列表冒充真实结果。支持单次选模的客户端保留默认项与手动 ID 兜底。
- 子进程继承现有环境；macOS 下从 `scutil --proxy` 补入缺失的 HTTP / HTTPS / SOCKS 代理，显式环境变量优先。`localhost`、`127.0.0.1`、`::1` 绕过代理。仅配置 PAC 的环境不会自动解析 PAC，需自行提供 `HTTP_PROXY` / `HTTPS_PROXY`。
- 非 macOS 不读取系统代理，使用环境变量。CLI 桥接已在 macOS 验证；Windows 原生运行尚未验收，静态模式不受影响。

### 使用与排错

1. 选作品和文档，补充本次需求或细纲，再点击生成。
2. 写作包包含当前功能需要的设定、规则与章节材料；内容会交给所选客户端及其服务商处理，可能消耗订阅额度。不要将“本地保存”理解为“模型推理完全离线”。
3. 输出先进入完整预览，点击「确认写回」才保存。取消保留对话结果；续写、修改与 Skill 追加支持冲突检查和撤销。服务只接受已登记目录内的 Markdown 相对路径；CLI 的工具权限仍由其客户端配置决定。
4. 连接失败先看界面原始错误。模型不受账户支持时重新检测并选择真实模型；检查客户端登录状态和本机代理，勿仅依据退出码判断。
5. 手工验收可访问 `http://127.0.0.1:8788/api/engines`，再对 `/api/generate` POST JSON：`{"engine":"codex","model":"","prompt":"只回复 OK"}`。空模型表示客户端当前默认。检测成功不代表目录中的每一个模型都完成了生成验收。

升级现有工作台：

```bash
python3 scripts/init_library.py /path/to/MyNovels --update-app
```

只备份并更新 `小说台.html`、`loki-themes.js`、`server.py`、`library.py` 和启动器。修改过的旧应用文件放进 `_workbench-backups/`；小说、作者规则与已有模板不覆盖。升级后重启原服务。

**边界**：不导出 Cookie / Token，不内置第三方模型中转网关，不静默改变其他客户端会话的全局模型，未经预览确认不保存生成正文；停止按钮中止接收与写回，CLI 可能继续执行。
